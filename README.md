# Gameatria

Interactive Hebrew Torah and Arabic Quran verse reader with traditional letter-number systems.

The static frontend lives under `docs/`. Start a local server with `python3 -m http.server 8080 --directory docs` and visit localhost:8080.

Data: Westminster Leningrad Codex from https://github.com/midvash/bible-data ; Tanzil Uthmani Quran text from https://tanzil.net/ and https://github.com/acfatah/tanzil . Scripture texts retain their original licenses.

Use `npm test`. GitHub Pages site source: `docs/`.
